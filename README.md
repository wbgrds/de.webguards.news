# WEBGUARDS News

Blog für Gründer – gebaut mit Jekyll + GitHub Pages.

**Live:** https://news.webguards.de

## Neue Artikel schreiben

Erstelle eine Datei in `_posts/` mit dem Format:

```
_posts/YYYY-MM-DD-titel.md
```

Inhalt:
```markdown
---
layout: post
title: Dein Titel
author: Dein Name
---

# Dein Inhalt hier
```

Committen und pushen → sofort live.
